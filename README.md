# Case Converter

Учебный плагин для IntelliJ Platform, лабораторная работа по ИСРПО.
Переименовывает символ под курсором или символы в выделенном блоке в `snake_case` или `camelCase`,
обновляя его ссылки через **Rename Refactoring** установленной IDE.

> Плагин работает с PSI-символами: можно выделить один идентификатор или несколько строк кода.
> Он не выполняет глобальную строковую замену. Поддержка переименования зависит от языка
> и установленных языковых плагинов IDE.

## Возможности

- Два действия в контекстном меню редактора **Case Converter**.
- Запуск на объявлении, использовании символа или выделенном блоке кода.
- Один Preview и одна команда Undo для всех выбранных имён; ссылки за пределами выделения тоже обновляются.
- Поиск ссылок, предварительный просмотр, проверка конфликтов и Undo/Redo средствами IDE.
- Обработка аббревиатур, цифр, кириллицы и крайних подчёркиваний.
- Настройки через **Settings → Tools → Case Converter**.
- Общая для проектов локальная статистика, диаграмма направлений и история операций.
- Подробные русские комментарии, автоматические тесты и материалы для защиты.

## Пример

До переименования поля:

```java
class Model { public int user_name = 1; }
class Usage {
    int read(Model model) {
        int user_name = 2; // Другая переменная: её имя останется прежним.
        return model.user_name + user_name;
    }
}
```

Поставьте курсор на поле `user_name` или на ссылку `model.user_name` и выберите
**Case Converter → Переименовать символ в camelCase…**.
После проверки Preview и подтверждения:

```java
class Model { public int userName = 1; }
class Usage {
    int read(Model model) {
        int user_name = 2;
        return model.userName + user_name;
    }
}
```

Связанные ссылки могут находиться в других файлах проекта. Одинаковый текст
в несвязанной переменной не означает ссылку на переименовываемый символ.

## Требования и сборка

- IntelliJ Platform **2026.2** (build **262**); сборка проекта нацелена на IntelliJ IDEA 2026.2.
- **JDK 25** для Gradle и компиляции; можно использовать JetBrains Runtime 25 с JDK.
- Gradle Wrapper включён в репозиторий: глобально устанавливать Gradle не нужно.
- Интернет для первой загрузки Gradle, SDK IDE и тестовых зависимостей.

Windows PowerShell:

```powershell
# Укажите каталог установленного JDK 25 (внутри него должна быть папка bin).
$env:JAVA_HOME = 'C:\path\to\jdk-25'
.\gradlew.bat test buildPlugin verifyPluginProjectConfiguration
```

Linux/macOS:

```bash
export JAVA_HOME=/path/to/jdk-25
bash ./gradlew test buildPlugin verifyPluginProjectConfiguration
```

Установочный архив: `build/distributions/case-converter-1.0.2.zip`.

Для разработки команда `./gradlew runIde` (Windows: `.\gradlew.bat runIde`)
открывает отдельную тестовую IDE с плагином.
Не нужно устанавливать разрабатываемую версию в основную IDE при каждом изменении.

В окружение `runIde` автоматически добавляется модуль Python для проверки `.py`.
Это не обязательная зависимость устанавливаемого Case Converter: в обычной IDE
поддержка языка должна быть установлена отдельно. После обновления сборки закройте
старую тестовую IDE и снова запустите `runIde`, чтобы изменился набор её модулей.

## Установка

1. Соберите ZIP командой `buildPlugin`.
2. В целевой IDE откройте **Settings → Plugins → ⚙ → Install Plugin from Disk…**.
3. Выберите ZIP из `build/distributions`.
4. Перезапустите IDE, если она предложит это сделать.

Публикация в Marketplace не требуется для лабораторной работы.
В GitHub Actions предусмотрена сборка и сохранение ZIP как артефакта запуска.

## Использование

1. Откройте проект и дождитесь индексации.
2. Поставьте курсор на имя переменной/функции либо выделите одно имя или **несколько строк кода**.
3. Откройте контекстное меню → **Case Converter** → нужный стиль.
4. Просмотрите найденные использования в штатном интерфейсе Rename и подтвердите изменения.
5. При необходимости отмените команду через **Edit → Undo**.

В выделении обрабатываются полностью попавшие в него имена объявлений и ссылок.
Повторные ссылки на один символ объединяются. Частично выделенные имена пропускаются.
Имена, уже соответствующие стилю, не меняются. Для текста без подходящих PSI-символов
выводится пояснение. Несколько курсоров не поддерживаются.
При индексации и в редакторе только для чтения действия недоступны.

Горячие клавиши назначаются через **Settings → Keymap**, поиск `Case Converter`.
Плагин не занимает сочетания клавиш автоматически.

## Преобразование блока

Выделите все строки и выберите snake_case:

```python
camelSnake = 0
camelSna12312ke = 0
camelSna85878ke = 0
camelSna345ke = 0
camelSna333ke = 0
camelSnak7879e = 0
camelSn7777ake = 0
```

После подтверждения Preview:

```python
camel_snake = 0
camel_sna12312ke = 0
camel_sna85878ke = 0
camel_sna345ke = 0
camel_sna333ke = 0
camel_snak7879e = 0
camel_sn7777ake = 0
```

Использования этих переменных вне выделения тоже обновляются. Можно выделять и строки
с использованием имён, например `print(first_name, last_name)`: объявления будут найдены
через ссылки. Обычные строки, комментарии и числа не заменяются текстовым поиском.

Весь план проверяется до изменения кода. Если новое имя недопустимо, пакет не запускается.
Если разные символы должны получить одинаковое новое имя, пакет отклоняется даже для
разных областей видимости — их следует переименовать отдельно. Остальные конфликты
проверяет IDE в штатном Rename. Не подтверждайте конфликтующий Rename и не исключайте
необходимые ссылки из Preview.

## Настройки

Все пользовательские параметры доступны в **Settings → Tools → Case Converter**.
**Apply/OK** сохраняет изменения; **Cancel** не применяет несохранённые изменения.
Кнопка восстановления значений по умолчанию также требует Apply/OK.

| Параметр | По умолчанию | Действие |
|---|---|---|
| Сохранять крайние подчёркивания | Да | `__user_name__ → __userName__`; при отключении → `userName` |
| Выделять аббревиатуры | Да | `HTTPServer → http_server / httpServer`; без правила → `httpserver` |
| Собирать статистику | Да | Учитывает завершённые переименования плагина |
| Максимум записей истории | 100 | От 10 до 1000; старые записи удаляются, итоговые счётчики остаются |

Предварительный просмотр и семантический Rename — обязательная часть действия.
Поиск обычных текстовых совпадений в строках и комментариях отключён.
IDE может обновлять ссылки, которые языковой плагин распознаёт внутри документации;
это отличается от замены всех одинаковых слов.

Примеры алгоритма при стандартных настройках:

| Имя | snake_case | camelCase |
|---|---|---|
| `userName` | `user_name` | `userName` |
| `HTTPServerURL` | `http_server_url` | `httpServerUrl` |
| `version2Value` | `version2_value` | `version2Value` |
| `__user_name__` | `__user_name__` | `__userName__` |
| `имяПользователя` | `имя_пользователя` | `имяПользователя` |

Повторные внутренние подчёркивания объединяются. Пустое имя и имя только из подчёркиваний
алгоритм не меняет. Преобразование не восстанавливает исходное написание аббревиатур:
`HTTPServer → http_server → httpServer`. Полученное имя дополнительно проверяется IDE
по правилам языка (например, нельзя переименовать Java-поле в ключевое слово `class`).

## Статистика и приватность

Откройте **View → Tool Windows → Case Converter** (обычно справа).

- Две горизонтальные полосы показывают доли операций snake_case/camelCase.
- Счётчики отражают завершённые операции и число переименованных целевых символов.
- Один блок = одна операция; отдельный счётчик показывает число переименованных символов.
- Повторные ссылки на один символ не увеличивают число символов. Блок из семи изменённых имён даёт 1 операцию и 7 символов.
- Сумма длин исходных имён измеряется в кодовых единицах UTF-16, как `String.length` JVM.
- История содержит время, стиль, число целевых символов и сумму длин их исходных имён.
- Пустая статистика отображается без деления на ноль.
- Окно обновляется после операций и применения настроек.
- Сброс удаляет историю и итоги после подтверждения; отменить сброс нельзя.

Нет сетевой отправки статистики. Исходные имена, код и пути файлов не сохраняются.
Настройки и статистика хранятся платформой в каталоге конфигурации IDE, в
`options/case-converter-settings.xml` и `options/case-converter-statistics.xml`.
Они общие для проектов данной установки IDE и переживают её перезапуск.

Отключение сбора сохраняет старые данные. Отмена Preview, отказ при конфликте и отсутствие
изменения имени не добавляют запись. Undo/Redo не изменяют счётчики:
они отражают историю выполненных команд, а не состояние кода.
Переименование штатной командой IDE вне плагина не учитывается.

## Границы поддержки

У плагина нет зависимости от Python. Он использует общий API IntelliJ Platform.
Однако семантическое переименование возможно только там, где установленный языковой
плагин умеет находить ссылки и выполнять Rename. Автоматические интеграционные тесты
покрывают Java и Python; работа с другими языками требует проверки в соответствующей IDE.

Текстовые файлы, динамические обращения по строке, reflection, внешние клиенты API,
неоткрытые проекты и некоторые генерируемые файлы не гарантированно покрываются
поиском ссылок. Проверяйте Preview и результат тестами проекта. Не исключайте необходимые
использования из Preview. Если IDE сообщает о конфликте, устраните его или отмените Rename.
Плагин не обещает исправить любые обращения, которые сама IDE не может разрешить.
