# История изменений

## [Unreleased]

## [1.0.2] — 2026-10-26

- Выделение блока кода: сбор полных PSI-имён и пакетное переименование с обновлением ссылок.
- Один Preview и одна команда Undo для блока; повторные ссылки на символ не дублируют операцию.
- Статистика различает одну пакетную операцию и число переименованных символов.
- Проверка совпадающих будущих имён до изменения кода; частичные имена не включаются в пакет.

## [1.0.1] — 2026-10-26

- Восстановлена поддержка Python в тестовой IDE runIde без обязательной зависимости выпускаемого плагина от Python.
- Добавлены регрессионные проверки Python: camelSnake = 0, ссылки и независимые переменные.
- Добавлено явное объяснение, если IDE распознаёт файл как обычный текст.

## 1.0.0 — 2026-10-26

- Реализовано переименование символов в snake_case и camelCase через Rename Refactoring.
- Обновление ссылок средствами IDE, предварительный просмотр и проверка конфликтов.
- Поддержка Undo/Redo без отдельной текстовой замены.
- Правила для аббревиатур и крайних подчёркиваний.
- Страница настроек с сохранением между запусками IDE.
- Локальная статистика, ограниченная история, диаграмма направлений и сброс.
- Удалены демонстрационное окно и обязательная зависимость от Python.
- Добавлены unit- и интеграционные тесты, конфигурация CI, инструкции для GitHub и защиты.
