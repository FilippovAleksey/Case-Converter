# Тестирование

## Результат локальной проверки

26 октября 2026 года, версия 1.0.2: **37 тестов прошли, ошибок и падений нет**.
Успешно выполнены `test`, `buildPlugin`, `verifyPluginProjectConfiguration` и
`verifyPluginStructure` на Windows с JDK 25 и IntelliJ Platform 2026.2.
Проверены алгоритм, Java/Python Rename, интерфейс настроек/статистики и XML-сериализация.
Интерактивная ручная приёмка и матрица других IDE/языков остаются отдельными проверками.

## Автоматическая проверка

Windows:

```powershell
.\gradlew.bat test buildPlugin verifyPluginProjectConfiguration verifyPluginStructure
```

Linux/macOS:

```bash
bash ./gradlew test buildPlugin verifyPluginProjectConfiguration verifyPluginStructure
```

Нужен JDK 25. При первом запуске Gradle скачивает SDK и тестовый фреймворк Java.
Режим `--offline` можно использовать только после загрузки всех зависимостей.

Отчёт JUnit/Gradle: `build/reports/tests/test/index.html`.
XML-результаты: `build/test-results/test/`.
Установочный ZIP: `build/distributions/case-converter-1.0.2.zip`.

## Что покрывают тесты

| Набор | Проверки |
|---|---|
| CaseConverterTest | Обычные имена, аббревиатуры и отключение правила, крайние подчёркивания, пустые строки, цифры, кириллица, турецкая локаль, повторное применение |
| StatisticsServiceTest | Итоги и лимит, сокращение истории без сброса итогов, независимость снимков, восстановление, сброс, границы настроек |
| RenameIntegrationTest | Ссылки между файлами, независимые локальные имена, строки и комментарии, методы, меню на объявлении и ссылке, конфликты, выключенный сбор, Undo/Redo, пакет полей и общий Undo/Redo, отказ от текста/ключевого слова, неизменившееся имя |
| PythonRenameIntegrationTest | Пример camelSnake = 0 и блок из 7 присваиваний, ссылки вне выделения, повторные ссылки, строки/комментарии, частичное выделение, коллизия будущих имён |
| SettingsAndWindowTest | Apply/Reset, отсутствие изменений до Apply, события диаграмм и таблицы, пустая статистика, сериализация XML |

Интеграционные тесты работают с настоящим PSI Java/Python и RenameProcessor.
В тестовом режиме платформа не показывает интерактивный Preview и выполняет Rename
синхронно. Поэтому автоматический прогон не заменяет проверку диалога человеком.

`verifyPluginProjectConfiguration` проверяет конфигурацию сборки,
`verifyPluginStructure` — структуру/метаданные архива.
Это не то же самое, что полный Plugin Verifier для матрицы всех IDE и версий.
GitHub Actions настроен в репозитории, но локальный запуск не подтверждает,
что workflow уже исполнился на GitHub.

## Проверка других языков

Повторите сценарий «объявление → использование в другом файле → одноимённый независимый
символ → Preview → Rename → Undo» в Kotlin, Python или JavaScript.
Убедитесь, что IDE действительно поддерживает язык и Rename.
Не делайте вывод о поддержке всех языков только из успешных тестов Java/Python.

Особенно проверяйте методы с переопределениями, свойства с аксессорами,
экранированные имена и динамические обращения. Результат зависит от языкового
процессора IDE. Плагин использует его механизм выбора цели и поиска ссылок.

## Если сборка не запускается

- `JAVA_HOME` должен указывать на JDK 25, а не на каталог bin.
- Для первой сборки нужны доступ к Maven/репозиториям JetBrains и свободное место под SDK.
- Ошибка offline о java-test-framework означает, что зависимости нужно сначала скачать онлайн.
- Если IDE выполняет индексацию, дождитесь её завершения.
- Если пункты меню отсутствуют, проверьте установку ZIP и совместимость build 262.
- Диагностика IDE находится через **Help → Show Log in Explorer/Finder**.
